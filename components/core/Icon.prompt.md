Lucide glyph wrapper. **Substitution flagged:** Alejandro's has no icon library of its own, so Lucide is used at stroke weight 1.5 to match the hairline borders.

Load once per page, before the bundle:

```html
<script src="https://unpkg.com/lucide@0.469.0/dist/umd/lucide.js"></script>
```

```jsx
<Icon name="phone" size={16} />
<Icon name="arrow-right" size={18} />
```

Icons are used sparingly: phone, arrow-right, chevron-down, map-pin, menu, x. **Never** an icon row standing in for a "Why Choose Us" section — that pattern was explicitly rejected. Never emoji.
