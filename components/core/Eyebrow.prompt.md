Uppercase label above a heading. It must carry a **fact** — a location, a service, a count — never a slogan.

```jsx
<Eyebrow tone="inverse" rule>Camp Hill, PA · Paver patio & seat wall</Eyebrow>
<Eyebrow tone="brand">Where we work</Eyebrow>
```

Good: "Mechanicsburg, PA · 640 sq ft". Bad: "Excellence in outdoor living".
