# Working rules — Alejandro's website

## Current phase: PHASE 1 — structural pass, page by page

Fix only what is obviously wrong:
- Missing or broken sections and links
- Bad mobile layouts
- Huge or badly cropped images
- Weak or obviously wrong heroes
- Duplicate or redundant sections
- Visible placeholder text / [VERIFY …] on screen
- Incorrect service information
- Pages that feel unfinished
- Major CTA or navigation problems
- Anything that materially hurts credibility or conversion

## Deferred to PHASE 2 — do not touch unless asked
- 5–10% spacing differences
- Small font-size decisions
- "Could this image be slightly better"
- Rewriting sentences that already work
- Micro-adjusting logo sizes
- Reordering sections when both orders work
- Deeper local SEO
- Making every page as elaborate as the patio page
